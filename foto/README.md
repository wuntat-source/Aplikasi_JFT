# Direktori Foto Pegawai JFT

Folder ini digunakan untuk menyimpan foto resmi pegawai JFT.

### 📌 Cara Menambahkan Foto Pegawai:
1. Simpan file foto ke dalam folder `foto/` ini.
2. Format penamaan foto yang didukung secara otomatis:
   - **Berdasarkan NIP**: `[NIP].jpg` atau `[NIP].png` (Contoh: `196807151994031019.jpg`, `198101272010011016.jpg`)
   - **Berdasarkan ID Pegawai**: `p1.jpg`, `p2.jpg`, dst.
3. Dimensi yang disarankan: **Rasio 1:1 (Persegi/Pas Foto Resmi)**, resolusi minimal 200x200 pixel.
4. Jika file foto belum ada di folder ini, sistem secara otomatis akan menampilkan inisial nama dengan warna latar belakang elegan sebagai fallback (*anti-broken image*).
